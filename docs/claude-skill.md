# Install the SAM Claude Skill

Use `releases/sam-claude-skill-v1.0.0.zip` for Claude.ai custom Skill upload where available. For Claude Code, copy the extracted `sam-aobpg` folder into the project `.claude/skills/` directory or the supported personal skills directory.

The Claude release omits OpenAI-specific UI metadata but uses the same `SKILL.md`, references, templates, and validation behavior.
