# Getting started

SAM has three installation targets and one shared workflow.

## Try the example

Open `examples/brands/sunny-spoon/manifest.yaml`, then ask SAM to create a campaign for the Weeknight Family Box. The companion campaign in `examples/campaigns/sunny-spoon-back-to-school/` shows the approved result.

## Create a real brand safely

Create real work under the ignored `workspace/brands/<brand-slug>/` folder. Start from `packages/sam-aobpg/assets/templates/brand-pack/`, complete Guided or Quick Setup, validate the pack, and retain its files for future sessions.

## Core path

`Brand → Source → Brief → Directions → Generate → Revise or Export`

SAM should always provide examples, contextual suggestions, and a recommendation when it has enough information.
