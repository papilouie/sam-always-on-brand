# Install the SAM OpenAI Skill

The canonical package is `packages/sam-aobpg/`. It contains `SKILL.md`, OpenAI UI metadata, references, templates, and validation scripts.

Use the generated `releases/sam-openai-skill-v1.0.0.zip` for an uploaded Skill, or install the folder using the method supported by the target OpenAI environment. The Skill is eligible for automatic invocation and can also be invoked explicitly as `$sam-aobpg`.

Keep real Brand Packs in an authorized project or workspace directory, not in the public repository.
